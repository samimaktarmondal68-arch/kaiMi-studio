# Keyboard Shortcuts

KaiMi Studio keyboard shortcuts for efficient workflow.

## Global

| Shortcut | Action | Context |
|----------|--------|---------|
| `Ctrl+N` | Create new project | Any page |
| `Ctrl+S` | Save current page | Workspace |
| `Ctrl+Shift+S` | Save as | Workspace |
| `Ctrl+K` | Global project search | Any page |

## Stage Navigation

| Shortcut | Action |
|----------|--------|
| `1` | Switch to Research |
| `2` | Switch to Script |
| `3` | Switch to Storyboard |
| `4` | Switch to Image Prompts |
| `5` | Switch to next available stage |

## Workspace

| Shortcut | Action |
|----------|--------|
| `Ctrl+S` | Save current stage |
| Left arrow | Previous stage |
| Right arrow | Next stage |

## Dialogs

| Shortcut | Action |
|----------|--------|
| `Esc` | Close current dialog |
| `Enter` | Confirm / Submit |

## Tips

- Stage shortcuts (1-5) only work when a project is open in the workspace
- `Ctrl+S` saves whatever stage is currently active
- `Ctrl+K` opens an instant search overlay — type to filter projects
- Use `Tab` to move between fields in dialogs
