# KaiMi Studio v1.0.0 "Aurora" — Release Notes

**Release Date:** July 27, 2026
**Version:** 1.0.0
**Codename:** Aurora
**Platform:** Windows 10/11 (64-bit)

## What is KaiMi Studio?

KaiMi Studio is an AI-powered creative intelligence suite for educational animation production.

## New Features

- Full 5-Stage Pipeline: Research → Script → Storyboard → Image Prompts → Export
- Multi-Provider AI: Gemini, OpenAI-compatible, custom AI providers
- Project Management: create, search, sort, filter, duplicate, rename, archive, favorite
- Export Formats: TXT, Markdown, JSON, ZIP, PDF, DOCX
- Version History, Global Search, Keyboard Shortcuts, Background Tasks, Autosave, First Run Experience

## Security

- Proprietary License, Path Traversal Protection, Filename Sanitization, Secret Masking, Tamper Detection

## Quick Start

1. Extract the ZIP
2. Double-click KaiMi Studio.exe
3. Follow the welcome dialog
4. Configure your AI provider in Settings

## Known Limitations

- No installer yet
- No code signing (SmartScreen warning on first run)
- AI features require a valid API key
