# KaiMi Studio Prompt Rules

These rules apply to every AI coding agent.

---

Before making changes:

1. Read:
   - docs/MASTER_SPEC.md
   - docs/ARCHITECTURE.md
   - docs/UI_GUIDE.md
   - docs/RELEASES.md

2. Understand the requested release.

3. Modify only the requested files.

---

Rules

Never remove existing functionality.

Never break imports.

Never rename public classes without instruction.

Never rewrite unrelated files.

Prefer reusable components.

Keep methods small.

Follow PEP8.

Use clear naming.

Return production-quality code.

Verify the project compiles.

Summarize changed files.

If uncertain, preserve existing behavior rather than guessing.

---

End of Prompt Rules.
