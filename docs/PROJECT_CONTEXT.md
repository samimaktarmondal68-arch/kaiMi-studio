# KaiMi Studio Project Context

## Overview

KaiMi Studio is a desktop application for managing the complete production workflow of AI-assisted YouTube content.

The software helps creators go from idea to final export through a structured workflow.

The goal is not to be another video editor.

The goal is to become the operating system for AI-assisted content creation.
