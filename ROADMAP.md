# Roadmap

KaiMi Studio development roadmap.

## v1.0.0 — Aurora (Current Release)

### Completed
- [x] Full workflow pipeline (Research → Script → Storyboard → Image Prompts)
- [x] Multi-provider AI support (Gemini, OpenAI, custom)
- [x] Project management (CRUD, search, sort, filter, archive, favorites)
- [x] Export system (TXT, Markdown, JSON, ZIP, DOCX, PDF)
- [x] Version history with compare and restore
- [x] Autosave with visual indicators
- [x] Global search (Ctrl+K)
- [x] Keyboard shortcuts
- [x] Background task queue
- [x] Notification system
- [x] Dark theme design system
- [x] Production logging
- [x] Crash handler
- [x] Session restore
- [x] First run experience
- [x] Application icon and branding
- [x] PyInstaller packaging
- [x] 78 integration tests
- [x] Performance benchmarking
