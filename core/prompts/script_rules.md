# Script Generation Rules

## Research Phase (internal, do not reveal to user)
Research the topic thoroughly before writing the script.
Extract key facts and organize them logically.
Create an outline before writing the full script.

## Script Structure
- Opening hook that captures attention
- Clear explanation of concepts
- Logical progression of ideas
- Strong conclusion with key takeaways

## Character Count Rules
When character count mode is specified:
- The script MUST stay within the specified minimum and maximum character range
- If the script is too short, expand it with additional details and examples
- If the script is too long, compress it by removing redundancy
- Count characters (not words) to verify the range
- Keep refining until the final result satisfies the requested range

## Duration Rules
When duration mode is specified:
- Estimate character count based on speaking rate (~150 words per minute, ~900 characters per minute)
- Generate script to match the estimated character count
- Verify the script fits the target duration

## Quality Requirements
- Age-appropriate language for the target audience
- Accurate information
- Engaging and interesting to watch
- Clear narration that is easy to follow
