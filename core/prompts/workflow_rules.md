# Workflow Rules

The script generation process has multiple internal stages:
1. Research - Gather information about the topic
2. Fact extraction - Identify key facts and data
3. Organization - Structure the information logically
4. Outline - Create a script outline
5. Script generation - Write the full script
6. Character validation - Verify character count within range
7. Automatic refinement - Expand or compress if needed
8. Final script - Return the completed script

The user should never see these internal stages.

All research is automatic and happens in the background.

The user only makes creative decisions:
- Topic and platform
- Video type
- Language
- Script target (character count or duration)
- Whether to upload voice audio
- When to generate image prompts
- When to export
